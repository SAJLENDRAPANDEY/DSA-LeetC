## 💡 Problem-Solving Approach

For every problem, I follow a consistent methodology:

1. ✅ Understand the problem statement thoroughly
2. ✅ Identify constraints and edge cases
3. ✅ Think through a brute-force solution first
4. ✅ Optimize the approach step by step
5. ✅ Analyze Time Complexity
6. ✅ Analyze Space Complexity
7. ✅ Write clean, readable, well-documented code
